# Dzeno Elevate

Create a premium, modern, animated corporate website for Dzeno Tech Nepal Pvt. Ltd., a technology company specializing in Software Development, IT Services, and IT Training.

The primary goal is to generate high-quality client leads, establish trust, showcase technical expertise, and position Dzeno Tech as a modern, reliable technology partner.

BRAND

Company: Dzeno Tech Nepal Pvt. Ltd.

Tagline: “We Build Technology That Moves Businesses Forward.”

Brand personality: premium, innovative, professional, futuristic, trustworthy, technical, confident, and approachable.

Use the existing Dzeno Tech logo provided by the user.

DESIGN DIRECTION

Create a premium dark futuristic interface inspired by Apple, Linear, Vercel, and modern high-end technology companies.

Use a near-black/charcoal background, off-white typography, and restrained electric blue/violet gradient accents. Avoid excessive neon, excessive gradients, generic IT templates, clipart, and stock photos of people using laptops.

Use large bold typography, generous whitespace, clean grids, subtle borders, glass effects where appropriate, elegant gradients, and sophisticated visual hierarchy.

Typography should use a modern font such as Inter or Geist.

The website must feel like a serious technology company rather than a basic local IT-services website.

NAVIGATION

Create a sticky transparent navigation bar with:
Dzeno Tech logo | Home | About Us | Services | Team | Careers | Contact | Let’s Talk →

On scroll, the navbar should gain a subtle dark/blurred glass background.

HOME PAGE

HERO

Create a cinematic hero section with a large headline:

“We Build Technology That Moves Businesses Forward.”

Supporting text:
“Dzeno Tech delivers innovative software, reliable IT services, and practical technology training designed to help businesses grow in a digital world.”

Primary CTA: Start a Project →
Secondary CTA: Explore Our Services

Create an abstract futuristic visual beside/behind the hero using glowing digital networks, connected nodes, subtle 3D geometry, data lines, and blue/violet lighting. Keep it elegant and minimal.

Add subtle floating animation and gradient movement.

SERVICES

Heading:
“Technology, Built Around Your Goals.”

Create three premium service sections/cards:

Software Development
Custom web and software solutions built for performance, scalability, and real business requirements.

IT Services
Reliable technology solutions, technical support, consulting, infrastructure, and digital services.

IT Training
Practical, industry-focused training designed to develop real technical skills.

Each service should have a minimal icon, short description, number, and Learn More → interaction. On hover, cards should subtly lift, glow, and animate the arrow.

WHY DZENO

Heading:
“Technology Should Create Possibilities.”

Show four values using elegant typography rather than generic icon boxes:

01 — Innovation
02 — Reliability
03 — Expertise
04 — Partnership

Use scroll-based reveal animations.

TECHNOLOGY

Heading:
“Built With Modern Technology.”

Create an elegant animated technology showcase with categories such as:
Web Technologies, Cloud, Databases, Artificial Intelligence, Automation, DevOps, Cybersecurity, Data & Analytics.

Use a subtle horizontal marquee.

PROCESS

“From Idea to Impact.”

FOOTER

Minimal premium footer with logo, tagline, navigation, services, social links, Privacy Policy, Terms, and:

© 2026 Dzeno Tech Nepal Pvt. Ltd. All rights reserved.

ANIMATION

Use moderate, premium animation:

Smooth page transitions

Scroll reveal

Fade/upward section animations

Subtle parallax

Floating hero elements

Animated gradients

Card hover effects

Button micro-interactions

Navbar blur on scroll

Animated statistics

Technology marquee

Timeline animation

Animations must feel smooth and expensive, never distracting. Support reduced-motion preferences.

RESPONSIVE

Create polished desktop, tablet, and mobile layouts. Mobile navigation should use a clean hamburger menu. Ensure no horizontal overflow, readable typography, touch-friendly buttons, responsive forms, and properly scaled hero visuals.

FINAL EXPERIENCE

The final website should communicate:

“Dzeno Tech is modern, technically capable, professional, trustworthy, and ready to handle serious technology projects.”

Prioritize lead generation, strong CTAs, excellent typography, whitespace, premium visuals, accessibility, responsive design, reusable components, and consistent design across every page.

Do not make the website look like a generic WordPress IT company template. Make it feel like a premium global technology brand.
